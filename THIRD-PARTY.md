## Vendored data

| Data | Version | License | Source |
|------|---------|---------|--------|
| IANA time zone database (tzdata) | 2026c | Public domain | https://www.iana.org/time-zones |
| Zone names (`src/stdlib/tzdb_names.inc`) | CLDR v45, as in the JDK 23 runtime | Unicode License V3 (Unicode-3.0) | Unicode, Inc. |
| Case, digit and word-boundary tables (`src/stdlib/unicode.c`) | Unicode Character Database 15.1.0, as in the JDK 23 runtime | Unicode License V3 (Unicode-3.0) | Unicode, Inc. |
| Single-byte charset tables (`src/stdlib/charset.c`) | Unicode mapping files: `CP1252.TXT`, and `8859-2.TXT` to `8859-16.TXT` (ISO-8859-2 to 9, 11, 13, 15 and 16) | Unicode License V3 (Unicode-3.0) | Unicode, Inc. |

The time zone database is under `third_party/tzdata/`. Its `LICENSE`
file says: "Unless specified below, all files in the tz code and data
(including this LICENSE file) are in the public domain." The BSD-licensed
files it names are code files that were not vendored.
`third_party/tzdata/VENDORING.md` records what was taken and how
`tzdata.zi` is built from it. The project's policy excludes public-domain
dependencies; this one was approved as an exception because there is no
licensed alternative and every major platform ships it.

The zone name table lists the English names of time zones (such as
"Pacific Standard Time") that Date.parse reads, generated by running the
JDK 23 runtime, whose locale data is Unicode's Common Locale Data
Repository (CLDR). Its license notice is in the appendix below.

The tables in `src/stdlib/unicode.c` give the upper and lower case of
each character, which characters are decimal digits, and the word
classes that toLower's final sigma rule depends on. They were generated
by running the JDK 23 runtime over every code point, so they are
Unicode Character Database data, under the same license and notice.

The tables in `src/stdlib/charset.c` give the Unicode character for
each byte from 0x80 to 0xFF in windows-1252 and in the ISO-8859 charsets
listed above. They are taken from the Unicode Consortium's mapping files
under https://www.unicode.org/Public/MAPPINGS/
(`VENDORS/MICSFT/WINDOWS/CP1252.TXT` and `ISO8859/8859-<n>.TXT`).
Each table was checked against its file, all 128 entries; a byte the
file leaves unmapped is U+FFFD. The files point to Unicode's terms of
use, which put Unicode data files under the Unicode License V3, so the
same notice covers them.

Each library's full license text is in its own directory:
`third_party/argparse/LICENSE`,
`third_party/pcre2/LICENSE`, and `third_party/bdwgc/LICENSE`.

PCRE2 is built with `SUPPORT_JIT` undefined (`third_party/pcre2/config.h`).
The separately licensed sljit compiler (`deps/sljit`) is not vendored.

bdwgc is unmodified upstream source. Its GNU-style build files, which the
upstream license singles out as carrying different terms and which
include some GPL-with-exception files, were not vendored and take no part
in this build. `third_party/bdwgc/VENDORING.md` records what was taken,
what was left out, and the source archive checksum.

## Platform runtime libraries

Supplied by the toolchain rather than vendored, and linked into the
built interpreter. Listed because on Windows some of it links
statically, which is not the case on the other targets.

| Platform | Component | Linkage | License |
|----------|-----------|---------|---------|
| Linux | glibc | dynamic | LGPL-2.1+ |
| Android | bionic | dynamic | BSD |
| Windows | msvcrt, kernel32, user32, advapi32, shell32 | dynamic (import libs) | Microsoft |
| Windows | mingw-w64 CRT (`libmingw32`, `libmingwex`, `libmoldname`) | **static** | Public domain, plus permissive files |
| Windows | winpthreads (`libwinpthread`) | static or DLL | Expat/MIT, with BSD-3-Clause and public-domain files |
| All | libgcc (`libgcc`, `libgcc_eh`) | static | GPL-3+ **with the GCC Runtime Library Exception** |

The Runtime Library Exception, version 3.1 section 1, permits combining
libgcc with independent modules and conveying the result "under terms of
your choice". Apache 2.0 is such a choice, so no copyleft obligation
reaches this project. This is the same arrangement as the Bison skeleton
above, and it applies to the Linux build equally.

## Notices required with a binary distribution

A distributed `aussomc` binary must be accompanied by the following
notices, in its documentation or other accompanying materials:

- argparse: the MIT notice in `third_party/argparse/LICENSE`.
- PCRE2: the copyright notices, conditions, and disclaimer in
  `third_party/pcre2/LICENSE`.
- Boehm-Demers-Weiser GC: the notice in `third_party/bdwgc/LICENSE`,
  reproduced in the appendix below.
- The zone name table, the Unicode tables and the charset tables: the
  Unicode License V3 notice in the appendix below.

The time zone database is public domain and needs no notice.

A distributed **Windows** binary additionally needs the winpthreads
notices in the appendix below. The mingw-w64 CRT is public domain and
libgcc's exception imposes no notice, so neither adds a requirement.

PCRE2's binary exemption states that the binary redistribution condition
does not apply down a chain of software: a package that includes a
package containing PCRE2 is not subject to the condition unless it uses
PCRE2 independently.

The Bison skeleton portions of the generated parser are covered by the
Bison parser exception and impose no notice requirement on the larger
work.

greatest is test-only. It is not linked into any shipped artifact, so it
imposes no notice requirement on a binary distribution either.
